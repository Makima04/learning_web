# UI 设计与功能文档

本文档描述 english_web 前端的 UI 设计与交互功能要求。代码实现应以此为准；若发现实现与本文档不符，以本文档为准并修复实现（除非本文档已过时，则先更新文档）。

> 状态机骨架见 `CLAUDE.md` 与 `web/srs.js`：卡片 `new → learn → review`，新词「评估 → 3 次练习 → 复习」。本文档补充各阶段的 UI 细则。

---

## 学习流程

### 新词评估（state=new）

**要求**：新词出现时，卡片正面**直接显示单词 + 三个评分按钮**，**不要**「点击/空格显示释义」的中间步。用户凭记忆直接自评，点按钮后才展开释义。

正面布局：

```
┌────────────────────────┐
│ 新词 · 评估        🔊  │
│                        │
│       <单词>           │
│                        │
│  [认识]  [模糊]  [忘记]│
└────────────────────────┘
```

三个按钮（顺序与文案固定）：

| 按钮 | 评分 | 结果 |
|---|---|---|
| 认识 | `good` | 进复习队列 |
| 模糊 | `hard` | 进 3 次练习 |
| 忘记 | `again` | 进 3 次练习 |

快捷键 `1/2/3` 对应三个按钮。

### 评估后全卡（assess-full）

点评分按钮后展开释义 + 例句，并给出后续按钮：

```
┌────────────────────────┐
│ 已标记「X」→ <去向>     │
│                    🔊  │
│       <单词>           │
│   <释义列表>            │
│   <例句 + 译文>         │
│                        │
│  [下一词]   [记错了]    │
└────────────────────────┘
```

- 「下一词」：进下一张卡。
- 「记错了」：仅对 `good`/`hard` 出现——看到释义后发现自己其实不会，把刚才的评分覆盖成 `again`，卡片回 learn 队尾重练。`again`（忘记）只给「下一词」。
- 快捷键：`1` = 下一词，`2` = 记错了（仅 good/hard 时）；空格 = 下一词。

### 3 次练习（state=learn, quiz=1/2/3）

- quiz=1：4 选 1，选出加粗词的含义。
- quiz=2：单词 → 中文翻面。
- quiz=3：中文 → 单词翻面。
- 细则待补充。

### 复习（state=review）

- 正面：单词（可翻面看释义）。
- 翻面后：释义 + 例句 + 评分按钮（again/hard/good/easy 等）。
- 快捷键：空格 = 翻面；翻面后 `1/2/3/4` = again/hard/good/easy。
- 细则待补充。

### 3 秒回忆提示（assess-front / review-front）

新词评估正面、复习正面渲染后启动 3 秒计时器。若用户在此期间未点按钮、未翻面、未按键，则在卡片正面底部**自动浮现真题例句（仅英文，不含翻译按钮）**作为回忆提示，下方评分/翻面按钮依旧保留可点。

- 仅 `assess-front`、`review-front` 两个阶段启用；`learn` 的 quiz 阶段不在范围内。
- 任何推进动作（点按钮、翻面、切卡、切屏）都立即清计时器。
- 浮现的例句块带 `.hint` 弱化样式（淡入、label 注明「回忆提示」），与正式例句块区分。
- 例句内词仍可点查义（`.c-word` 委托生效）。

## 设置页

左侧分类导航 + 右内容布局，5 个分类：

| 分类 | 所含项 |
|---|---|
| 学习 | 每日新词数、记忆方向 |
| 发音 | 自动发音、点词朗读、语速 |
| 翻译 | 翻译服务（模型/并发/刷新/测试/翻译管理入口） |
| 账号 | 登录/注册/登出 |
| 数据 | 导出/导入/重置、关于 |

- 默认选中「学习」。
- 窄屏（≤880px）导航改为顶部横向标签，可滚动。
- 选项变更即时持久化（`applySettings` → `Store.saveSettings`）。

### 点词朗读

- 路径：设置 → 发音 → 点词朗读。
- 开启时（默认）：例句/原文点词弹释义卡自动朗读单词。
- 关闭时：不自动朗读，但释义卡上的 🔊 按钮仍可手动点读。
- 与「自动发音」独立：「自动发音」控制卡片渲染时是否朗读目标词，「点词朗读」控制点词查义时是否朗读。

## 真题原文阅读

`studyMode: "passage"` 背完进 reader（`#screen-reader`）。

- 原文按段、按句渲染，每个句子包 `<span class="r-sent" data-en="...">`，命中词高亮（`.r-hl`）。
- **空格 / Enter**：显示当前激活句（`.r-sent.active`）的中文翻译，译文插入到该句下方的 `.r-trans` 块；再次按空格推进到下一句并滚动居中。
- 译文走 `LLM.translate` → 后端 `/api/translate`，按句文本去重命中 `translations` 表，已翻译过的句子瞬返。
- 句内任意词库收录的词（含变形还原，见下）可点查义弹 popover。

## 词形还原（点词查义 / 原文高亮）

`lookupWord(surface)`（`web/app.js`）负责把原文里的变形形还原到词库原形，决定点词能否弹释义卡、原文词能否高亮。还原顺序（先命中先返，原形优先）：

- 原形（surface 本身）
- 复数 / 动词变形：`-s`、`-es`、`-ing`、`-ed`、`-ing→e`、`-ed→e`、`-ies→y`、`-ied→y`
- 副词：`-ly`、`-ely→e`、`-ily→y`（quickly→quick, bravely→brave, happily→happy）
- 抽象名词：`-ness`、`-ment`、`-tion→te`、`-sion→d`、`-ity`
- 形容词派生：`-ful`、`-less`（careful→care, careless→care）

`highlightTarget`（例句目标词高亮）与 `highlightWords`（原文高亮）复用同一套变形判定。

> 已知不覆盖：不规则变形（`ran→run`、`better→good`、`children→child`）与 `-ly` 之外的双后缀（`consciousness→conscious` 走 `-ness` 可命中，但 `articulately→articulate` 经 `-ly` 命中）。如遇漏网，补 `lookupWord` 的 `tries` 即可，全文四处（popover、例句高亮、原文高亮、原文命中判定）都会受益。
