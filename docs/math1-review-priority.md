# 数学一分题型复习优先级（首版）

入口：左侧“复习性价比” → 顶部工具条（学科 / 题型 / 分科 / 排序，数学可选练习题集）→ 首屏 Top3 行动卡 → 排行表 → 右侧下钻抽屉。路径 `/review-priority?subject=math`。
旧路径 `/kg/math/review-priority` 自动迁移并保留题型、分科、考点参数；导航独立记住上次选择，不占用知识图谱的导航记忆。

极值考点新增「知识复习」入口（行动卡、排行行内、下钻抽屉及图谱考点页），进入 `/review-priority/knowledge/calc.m.ext`。正文按识别信号、解题路线、旁侧技巧组织，并连接真实题目与现有练习评分；详见 [数学知识复习模板](math-knowledge-review.md)。

## 页面结构（2026-11 重设计后）

- 学科、题型、分科、排序放在吸顶工具条，数学的练习题集另起一行；统计口径收进 ⓘ 弹层，底部 details 保留完整来源说明。
- 首屏是「结论条 + Top3 行动卡」：判断句（几类未诊断、前 3 名覆盖近五年多少分值）+ 每张卡给性价比分、每年占分、预计提分、预计耗时和一个「开始练」。
- 排行表展示「性价比」（同科目同题型内归一化 0–100）、主考归属占分、包含辅助考点的考查年份、掌握度与成本。只有辅助考查而未拆分小问分值时显示「综合考查 / 收益未估」，不把零主考归属误写成低收益。点行 = 下钻抽屉，点 ▶ = 直接做题。
- 下钻抽屉：结论句 → 占分/缺口/成本三因子 → 任务式训练队列（可「连续做 3 题」，标记后自动进入下一题）→ 真题依据（年份胶囊直接跳原题）。
- 宽屏（≥768px）在训练队列里点某道题，题面放大到左侧「作答台」：题卡宽上限 880px、题干 17px、选项 16px，短题垂直居中，长题在台内滚动；表头给 `当前/总数` 与上一题 / 下一题，队列里正在做的那道题高亮并标「作答中」。窄屏没有左侧空间，题卡仍在抽屉里，排在队列之前，换题时自动滚到视野内并提供上一题 / 下一题。
- 作答台键盘：`←` / `→` 换题，`f` 切换「大屏」模式（隐藏右侧队列，题卡放宽到 1080px），`Esc` 先退出大屏再关闭抽屉；输入框 / 下拉聚焦时不抢键。大屏态只隐藏右栏、不卸载，退出后队列的滚动位置仍在。
- `src/lib/kg/reviewRoi.ts` 负责把 `priority` 换算成 ROI 分数、每年占分、预计提分（按缺口估算）与粗略耗时；排序仍以 `math1Analysis.priority` 为准，只有一套口径。
- 有记录的考点少于 3 个时，性价比只显示高/中/低，不显示分数，避免样本不足时的数字噪音。

## 数据与统计口径

- 2009—2026 共 408 道题：大题 144、选择题 156、填空题 108。
- 2009—2020 每年选择 8 题/32 分、填空 6 题/24 分、大题 9 题/94 分；2021—2026 每年选择 10 题/50 分、填空 6 题/30 分、大题 6 题/70 分。
- 2009—2026 全部 408 题按归档题干逐题重新分类（AI 复核，复杂与歧义题对照解析），不再直接采用旧来源粗标签。源文件为 `scripts/math1_question_review.json`，每题有主考点、辅助考点、考法、复核理由、原题与解析页码、题干文本哈希；每年绑定原卷与解析文件哈希。
- 完整 408 题分类表及逐考点汇总见 [逐题复核表](math1-question-review.md)。主标签纠正包含基与过渡矩阵、三重积分、矩阵相似、方程有解性、切比雪夫不等式和欧拉方程等。
- 2026-11 考点去重（`scripts/retag_math_kp.py`，幂等）：考点按「题目问什么」划分，公式/方法是考点下的模板。微分等式/不等式证明并入中值定理（`calc.d1.ineq→calc.d1.mvt`）、不定积分计算并入积分技巧（`calc.i1.indef→calc.i1.tech`），旧进度经 `kpAlias` 一次性迁移；格林/斯托克斯模板归第二类曲线积分、高斯模板归第二类曲面积分，`calc.m.formula` 收窄为「散度、旋度与保守场」（id 不变，真题辅助标签语义仍成立）。洛必达与泰勒更名「泰勒公式与余项应用」，洛必达条件移入求极限技巧。
- “考频”包含主考点和辅助考点，以出现年份去重，题数另计；分值仍仅归唯一主考点，避免综合题重复计分。辅助标签只记录直接要求或实质使用的知识，不展开先修闭包。近五年为数据集最新的 2022—2026，三种题型分别统计。
- 抽屉真题依据区分主/辅标签，并给出全部标签、考法、分类理由和原题链接。从辅助考点进入真题时，上一题/下一题保留该考点上下文。
- 个人排序用每年该考点在当前题型的分值 / 当年当前题型总分的均值，混合长期 40%、近五年 60%，避免跨题型或跨年代分值混算。

## 个性化与训练

个人排序再乘掌握缺口、薄弱与到期小幅加权，除以相对补齐成本。成本为人工 1—3 档估计，不是观测时长或提分预测。
未做过、仅标已学的考点保持“待诊断”，不记作不会。有当前题型的练习记录时，使用最近至多 10 道题的标记、按新近程度加权（会 .9、模糊 .4、不会 .1）；有共享图谱参考时按练习 70%、图谱 30% 合并。
缺少当前题型练习记录时，明确显示“图谱掌握参考”，不把其他题型的记录显示成当前题型的作答记录。真题整题自评只作为主考点的同题型作答样本，不把综合题通过自动当作每个辅助考点都已单独检验；辅助题的全部考法也不扩散成当前考点的必练技巧。

训练候选从现有李林 880、张宇 1000 前端目录取得，目标题和补基础题均与当前题型一致，无匹配时不跨题型凑数。
数学页的吸顶工具条与训练抽屉均可切换「全部题集 / 李林 880 / 张宇 1000」，默认同时使用两者。单选时通过 `src=lilin880` 或 `src=zhangyu1000` 保留在 URL，刷新与切换题型、分科后仍生效；首页开始练、技巧代表题、补基础、到期复测及全部可练题共用筛选后的候选。切换来源会清空当前临时练习队列并作废尚未完成的加载，没有匹配题时提示切换题集，不从未选来源补题。个人排序仍使用完整历史作答证据，学习记录沿用原有账号同步。
首屏各推荐至多 1 道先修基础题、2 道同考点题；可每次再展开 8 道，最终查看全部可练候选。
每本显示导入总量、当前题型题量、同考点数量与当前可练候选数量（含补基础）；导入量不等于已核验原书逐题无遗漏。
方法标签交集只显示“方法标签匹配”，不能视为已人工确认的同解法；无细标签则只显示“同考点”。
已标会的题会避开，到期错题可重练，间隔未到的错题不提前重复推荐。
作答复用 `applyWangdaoPractice`，写图谱与错题集；登录后沿用 `syncQueue` 和 `syncAccountData`，不新增本地独占的学习进度。

## 可复现的数据管线

```bash
.venv/bin/python3 scripts/collect_math1_exams.py
.venv/bin/python3 scripts/gen_math1_analysis.py
```

来源 URL、哈希固定在 `scripts/math1_exam_sources.json`；标签映射、成本及 2026 补充在 `scripts/math1_topic_mapping.json`。
生成的分析数据是 `frontend/src/data/kg/math1Questions.json`，PDF 在 `frontend/public/math/exams/math1/`，不要直接编辑。
生成器校验来源元数据哈希、归档 PDF 哈希、逐年题数和分值，再生成带有原题/答案页码的引用。

## 检查

`math1Analysis.test.ts` 检查 408 题逐年/逐题型覆盖与分值、图谱引用、分题型归一化、掌握记录来源区分、推荐不串题型、展开候选完整性，以及错题间隔。
页面复用原有练习卡，支持原题图、答案、备注、收藏及会/模糊/不会标记。

## 408 共用入口

`/review-priority?subject=cs408` 支持大题/选择题，以及数据结构、组成原理、操作系统、计算机网络。
真题标签与分值来自现有 `papers/cs408`，`gen_cs408_frontend.py` 新增生成 `cs408ReviewQuestions.json`，只分配主考点分值，不累计辅助考点的整题分值。
2009—2011 规则草稿、2026 回忆版不参与排行；另发现 2015/2021 来源分值合计异常，暂不参与榜单，保留原题入口，不通过按比例改分或猜测题号来凑足 150 分。
当前使用 12 个有效年份、564 道题；近五年 2021—2025 中有 4 个有效年份，分母据实际样本显示。
成本为生成脚本内的人工相对初估，默认中档；页面说明其局限。

408 配套练习使用现有王道题库（2886 题），点击后按需加载完整题干，再复用练习卡更新图谱与错题集。
对应真题提供直接作答和展开答案深链。排序优先使用同题型的教辅标记、真题自评与真题作答，按题取最新证据去重。
数学与 408 共用排序、题型匹配与学习记录读取逻辑，保持原有服务端同步路径。
