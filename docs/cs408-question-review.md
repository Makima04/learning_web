# 408 知识复习：结合原题讲解

2026-11-09 起，知识复习的默认正文改为围绕具体原题组织，教材自编小例题保留为「补基础」路线。范围为四科 92 个知识点：91 份逐题教案，1 个显式来源缺口。

## 用户看到的学习流程

1. 真实题目：显示真题年份题号，或王道的科目、章、小节名称和小节内题型题号。
2. 识别本题的条件与考法，再阅读本题用到的知识和公式。
3. 按具体数据与约束推演，展示结论、排错依据和必要的算法代码。
4. 展开条件变化后的处理方法，完成本题自测，再独立重做原题或同考点补充题。

每份正文均针对注明的原题重新编写，未直接复制题库 OCR 解析。对题干中缺少图形但算法要求不依赖示意图的题目，以及存在明显 OCR 排版破损的题干，使用标为「题意摘录」的文字，完整原题仍可打开。

## 内容与生成

- 人工教案源：`scripts/cs408_knowledge_cases.py`。逐项维护原题 ID、切入点、三步推演、答案和条件变化。
- 生成脚本：`scripts/gen_cs408_knowledge_lessons.py`。
- 前端产物：`frontend/src/data/kg/cs408QuestionLessons.json`，不能手改。
- 输入题库：已提交的 `frontend/public/cs408/<year>.json` 与 `wangdao2027.json`。不依赖被忽略的本地原始 PDF 或中间文件。
- 概念与公式继续由 `cs408TextbookReview.ts` 提供，`cs408QuestionReview.ts` 将其与原题教案组合。

```sh
.venv/bin/python3 scripts/gen_cs408_knowledge_lessons.py
.venv/bin/python3 scripts/gen_cs408_knowledge_lessons.py --check
```

生成时核对题目存在、科目、答案键和覆盖范围，并记录题库输入文件的 SHA256。题库更新后需重新核对教案并重建；前端测试会检测过期来源。

## 来源、评分与边界

知识点与题目的教学关系由教案明确指定，允许补充旧分类中漏掉的相关题目。讲解可引用不在性价比统计集中的题目，但不因此改变原统计范围、考频或分值。

王道主例题重做时以本节已经核对的知识点记录评分，避免旧目录错误标签污染进度。沿用原题 ID、现有图谱评分、错题/收藏和账号同步；阅读遮挡与口头自测只影响当前阅读，不额外伪造学习完成记录。真题独立作答仍进入已有真题页面及同步流程。

`co.io.channel` 尚未找到可独立讲解 I/O 通道方式的可靠原题，页面和目录均明确标为待补，保留原教材例题。内存多通道带宽题属于另一知识领域，不能用来补齐此项。

本次不改变「算法设计 / 应用分析」复习性价比路线的设计状态；实现的是知识复习正文的原题讲解，以及王道出处标注。
